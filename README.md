# Dotfiles Backup

CachyOS Hyprland rice configuration backup.

## Backed Up Configs

| Path | Description |
|---|---|
| `.config/hypr/` | Hyprland compositor, hypridle, hyprlock, hyprpaper, scripts, wallpaper |
| `.config/waybar/` | Waybar bar config, styles, custom scripts |
| `.config/rofi/` | Rofi app launcher config |
| `.config/dunst/` | Dunst notification daemon |
| `.config/swaync/` | SwayNC notification center |
| `.config/wlogout/` | Wlogout logout menu |
| `.config/swaylock/` | Swaylock lock screen |
| `.config/gtk-3.0/` | GTK3 theme settings |
| `.config/gtk-4.0/` | GTK4 theme settings |
| `.config/Kvantum/` | Kvantum theme selector config |
| `.config/nwg-look/` | nwg-look GTK theme settings |
| `.config/qt6ct/` | Qt6 appearance settings |

## Scripts

- **`backup.sh`** — Sync dotfiles into this repo (run before making rice changes)
- **`push.sh**` — Commit and push to GitHub (`push.sh "optional message"`)
